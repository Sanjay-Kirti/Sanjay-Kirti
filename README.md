###  Featured Work

**🤖 DM Triage Agent** — *AI agent for Instagram DM routing, human-in-the-loop*
Flask + SQLite + Meta Instagram Graph API + Featherless AI inference, routing through the Caspian SDK. High-value conversations pause for owner approval before an automated response goes out.
`Agent → Human approval → Action`
🏆 1st place / 1200 entrants — Caspian AI Buildathon · [Repo](https://github.com/Sanjay-Kirti/dm-triage-agent)

** Caspian SDK — Cross-Channel Streaming**
Contributed real-time message streaming (post + edit) across Telegram, Discord and Slack to an open-source AI agent-communication SDK, plus a bounded-retry fix for a race condition surfaced during live testing.
[Pull Request #54](https://github.com/TryCaspian/caspian-sdk/pull/54)

** kuberna-labs — Dispute Contract Hardening**
Fixed a misleading counter naming bug and added missing edge-case guards (duplicate-registration check, role verification, access control) to a Solidity `Dispute` contract on an on-chain AI agent platform.
[Pull Request #78](https://github.com/kawacukennedy/kuberna-labs/pull/78)

** Full-Stack Products**
Frontend → Next.js / React / TypeScript · Backend → Node.js, Django REST Framework, PostgreSQL · Infra → AWS EC2, WebSockets · Web3 → Solidity, Ethers.js
